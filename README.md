# Эмулятор оболочки ОС — Вариант №12

Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS) в памяти.

## Возможности

- REPL с приглашением, содержащим имя VFS.
- Парсер с раскрытием переменных окружения реальной ОС (`$HOME`, `$USER`, ...).
- Команды-заглушки `ls`, `cd` (этап 1), реальная логика `ls`, `cd` (этап 4).
- Команда `exit`.
- Конфигурация через командную строку: путь к VFS, путь к стартовому скрипту.
- Стартовый скрипт останавливается на первой ошибке.
- VFS загружается из JSON-файла в память; бинарные данные — base64.
- Обработка ошибок загрузки VFS (файл не найден, неверный формат).

## Команды

| Команда | Описание |
|---|---|
| `ls [path]` | Список содержимого каталога |
| `cd [path]` | Смена текущего каталога |
| `exit` | Выход из эмулятора |

## Сборка и запуск

```bash
# Запуск без VFS (VFS по умолчанию пустая)
./run.sh

# Запуск с VFS и стартовым скриптом
./run.sh -v vfs_data/deep.json -s startup/startup.txt
